# ChessBro

PWA offline para aprender ajedrez desde lo básico hasta ~1800 de Elo.
Diseño: [`docs/DISEÑO.md`](docs/DISEÑO.md).

```sh
npm install
npm run dev     # desarrollo
npm test        # tests
npm run build   # build de producción con service worker
node scripts/e2e-offline.mjs   # prueba sin conexión (necesita Playwright; ver el script)
```
